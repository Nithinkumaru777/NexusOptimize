Process Assassin Ultra Game Mode

Drops browsers, Discord, Spotify and launcher helpers to Idle CPU priority so the game gets the cores. Nothing is closed. Turning it off (or quitting NexusApp) puts them back to Normal. Apps opened after you switch it on are not affected — toggle again to catch them.

Mod library

Install, switch on and off, and browse Nexus Mods for —

File-based only. Nexus copies files into the game's own mod and config folders and backs up anything it overwrites. It never touches the game's process or memory. Remove restores the folder exactly as it was.

Installed mods Applies on next launch

Archives are unpacked to a staging folder and routed by file type: .pak → Paks/~mods, matching .ini → the game's config folder, ReShade presets → next to ReShade. Code files (.dll/.exe) are never installed. Switching off removes the files and restores originals.

Mod Bisect Find the broken mod

Game broken with mods on? Bisect switches half of your ON mods off. Launch the game, say whether it works, and it halves again until one mod is left (about log₂(n) launches). Close the game between steps. Stop puts every mod back ON.

ReShade preset Live via ReShade

Drops a preset .ini next to ReShade. While playing, pick it from ReShade's preset list (Home key). With the game closed it also becomes the startup preset.

Config swap Next launch

Replaces one config file (Engine.ini, GameUserSettings.ini, …) with your version. Games rewrite configs on exit, so close the game first.

About

Nexus Optimize & Mod (NOM) v2.1. GPU data comes from NVML and CPU/RAM data from psutil; latency is measured live over TCP. Frame rate comes from PresentMon (ETW, out-of-process); without it the app shows "—" instead of an invented number.
